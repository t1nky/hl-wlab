Install Bun 1.4.3, run bun install --frozen-lockfile, then bun run build. To rebuild the trace core, install Zig 0.15.2 and run sh tools/build-web.sh or tools/build-web.ps1. Full instructions are in docs/DEVELOPMENT.md.
